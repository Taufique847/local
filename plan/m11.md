Bilkul. **M11 ko M10 ke upar build karna hai**, aur iska main purpose hoga **AI Tool Calling / Function Calling**. Is module ke baad AI sirf baat nahi karega, balki controlled backend tools ko invoke kar paayega—jaise customer lookup, lead creation, availability check, appointment creation, SMS request, etc.

Lekin ek important architectural rule: **LLM ko direct database access kabhi nahi dena hai.** AI → validated tool → backend service → database/external API. Isse security aur tenant isolation maintain rahega.

find_customer

Find an existing customer.

phone number.

{

- prevent malformed input
- limit input length

Before creating:

1. Normalize phone number.
2. Check duplicate customer.
3. If existing customer found:

The backend owns customer identity.
