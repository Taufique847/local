# M4 — HVAC OWNER DASHBOARD

The goal of M4 is to replace the temporary `/app` page with the first real SaaS application dashboard for an HVAC business owner.

The dashboard should feel like a serious, production-quality B2B operations platform.

==================================================

# 1. CORE PRODUCT CONTEXT

==================================================

BlueCollar AI is an AI Employee SaaS platform for US blue-collar/home-service businesses.

The first target industry is HVAC.

The future product will help HVAC businesses:

* answer customer calls
* capture leads
* qualify leads
* book appointments
* send SMS
* follow up with customers
* manage customers
* manage appointments
* review calls
* configure AI employees
* monitor business operations

M4 does NOT implement those systems.

M4 creates the central dashboard where those systems will eventually be visible.
